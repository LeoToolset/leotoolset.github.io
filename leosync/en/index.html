Reliable Android file synchronization and transfers.

LeoSync provides resumable SMB file transfers, multiple synchronization profiles and reliable control of your files between Android, PC and NAS.

Resumable SMB file transfers

If a file transfer between Android and a PC or NAS is interrupted, LeoSync can resume the upload. Up to four transfers run in parallel. Files are permanently renamed only after a complete transfer.

Manage multiple synchronization profiles

Create multiple synchronization profiles for different PC and NAS destinations. Use simulation to preview the changes before an Android file synchronization is performed.

Preserve file timestamps during synchronization

When transferring files to your PC, LeoSync preserves their modification timestamps from the Android device. This keeps important date information intact after synchronization.

Recycle bin for synchronized files

The LeoSync recycle bin protects deleted and replaced files. You can configure the retention period individually for each synchronization profile. Files are removed after 30 days by default. Setting it to 0 keeps them indefinitely.

Safety brake against mass deletions

If many files would be deleted at once (default: more than 20%), an entire folder is missing, or a newly chosen folder does not match the previous state, LeoSync pauses the folder sync and asks you first. The threshold can be set per profile.

Simulation and approval before the first run

After creating a profile, you can first simulate what would happen without anything being transferred. A new profile only starts automatically after you have synchronized it manually once.

Custom month folders

Month folders can be renamed as long as the month number remains. Existing folders continue to be used. For photo profiles you can choose between three folder structures: Year\Month - Country (default), Year\Country\Month or Year\Month\Country. The choice can be made until the profile's first sync.

Backup reminders

If new photos are waiting and no backup has been performed for some time, LeoSync can remind you. The interval is configurable.

Free up space on your phone

LeoSync can remove old files from your phone once they are verifiably stored on your PC. Each file is checked on the PC first. You select by age, folder, file type, size and exceptions, with a preview. On Android 11 and later, photos and videos go to the gallery's recycle bin.

File filters for folder profiles

With "Only these files" and "Exclude these files", you use patterns such as *.pdf or Temp/** to decide what gets synchronized.

Statistics for your backups

LeoSync shows the number and storage size of your backed-up photos and videos per year and country.

Back up and restore your profiles

Profiles, settings and sync status can be exported to a file and imported again. SMB passwords are included only if you protect the export with an export password.

SMB encryption per profile

You choose per profile whether the transfer is encrypted: Off, If possible (default) or Required. With "Required", no connection is made and no password is sent unless encryption is available. Encryption exists from SMB 3; "Test connection" shows whether it is active.

Pause and "Only while charging"

You can pause automatic sync for a set time or "forever", after which LeoSync only syncs when you trigger it. If you wish, sync runs only while the mobile is charging.

History and diagnostics

The history lists every run with its log and can be exported through the Android share menu. The copyable diagnostic data contains no passwords, user names, computer names or folder names. For common manufacturers, the app shows which settings keep background operation reliable.

Store Android photos on your own PC or NAS

LeoSync transfers your photos, videos and files directly via an SMB network share to your Windows PC or NAS. You do not need a cloud account for this. You decide where your Android backup is stored.

Local GPS and country detection

LeoSync identifies the country of your photos directly on your Android device using GPS metadata and an integrated database. Geographic identification does not require an external geolocation service or cloud lookup.

Securely store SMB passwords with Android Keystore

Credentials for your SMB network shares are stored with protection provided by the Android Keystore. Your SMB passwords are not automatically transmitted to the developer. This keeps the credentials for your PC or NAS under your control. For each profile you can also enable a PC ID check: LeoSync recognises your PC before the user name and password are sent. This protects against your credentials going to an unknown server on a foreign network.

Frequently asked questions about Android photo backup and synchronization.

Answers about LeoSync, automatic photo backup, NAS synchronization and file transfers via SMB.

Can I back up Android photos with LeoSync without using the cloud?

Yes. LeoSync backs up photos and videos directly from your Android smartphone to your own PC or NAS. Transfers use SMB over your local network. You do not need a cloud account or an external cloud storage service.

Can I back up Android photos to a NAS?

Yes. With LeoSync, you can automatically back up photos and videos from your Android smartphone to a NAS. A reachable SMB2 or SMB3 network share and a user account with the required write permissions are needed.

Can I synchronize files between Android and PC?

Yes. With LeoSync folder profiles, you can synchronize files between your Android smartphone and a Windows PC. Transfers work from mobile to PC, from PC to mobile or bidirectionally via an SMB network share.

What happens when a synchronization conflict occurs?

LeoSync uses three-way reconciliation between mobile, PC and the last known state. If the same file was changed on both sides, you decide per file: keep the phone version, keep the PC version or keep both (the phone version then gets the suffix _conflict-phone). Alternatively, you can set a profile so that the newer file wins automatically. The losing version always goes to the recycle bin. With one-way profiles, the source wins.

How can I restore deleted files in LeoSync?

The integrated LeoSync recycle bin keeps deleted files and replaced file versions. You can restore individual files, entire folders or all files from a specific day. This allows you to recover accidentally deleted or overwritten files.

Is LeoSync free?

Yes. You can download LeoSync free of charge from GitHub Releases. The app is released under the MIT license, and the source code is available in the GitHub repository. The current version is a beta.

How can I get help?

A step-by-step guide with solutions for common messages is available on the help page; further documentation is in the GitHub repository. Submit questions, bug reports and suggestions through GitHub Issues.

What permissions does LeoSync require?

To use all features, LeoSync requires certain permissions that you must explicitly grant, depending on your Android version and how you use the app.

1. Photos and videos

LeoSync needs access to your photos and videos to back up and synchronize your selected media.

  • Photos: Allows access to your pictures.
  • Location in photos: Allows reading the GPS data stored in your photos so that LeoSync can create the country folders.

2. Location and Wi-Fi detection

Android requires certain location permissions to automatically detect the name of the connected Wi-Fi network (SSID). To allow LeoSync to detect your Wi-Fi network in the background, the setting 'Location – Allow all the time' may also be required.

  • Location access: Enables the Wi-Fi detection required by Android.
  • Background location access: Allows Wi-Fi detection even when LeoSync is not open.

Privacy note: LeoSync uses the two location permissions in this section exclusively for Wi-Fi detection. Your current location is neither determined nor transmitted. Country detection is performed independently and entirely offline using GPS coordinates stored in your photos and videos.

3. Notifications

LeoSync needs your permission to notify you about ongoing and completed synchronizations. On Android 13 and newer, notification access must be explicitly granted.

4. Battery optimization

To ensure that background synchronizations run as reliably as possible, LeoSync may request an exemption from Android battery optimization. This reduces restrictions caused by power-saving measures. You may need to explicitly approve this setting.

5. Installing app updates

If LeoSync installs updates directly using APK files, Android may require permission to install apps from this source. You must then confirm the installation of the update.
